ALISHBA KHAN — A LITTLE BIRTHDAY STORY

Open index.html in a modern browser. No install or build step is required.

The experience includes:
- A password gate with a blank circular photo placeholder
- Seven Roman Urdu and English questions with live A=1, B=2, C=3, D=4 scoring; Love % = points ÷ 28 × 100
- A birthday reveal with an original synthesized piano accompaniment and Happy Birthday melody
- A press-and-hold candle blow-out with animated airflow, candle extinguishing, cake-slice animation, and confetti
- A memory card, your custom Roman Urdu birthday letter, and an interactive date-night mixer game
- Responsive layouts and reduced-motion support

The password check and score calculation run in the browser. The password does not
appear as a hint on the page. The date shown in this version is November 16,
following the latest date format supplied for the password.

The cake is currently a layered CSS illustration.
